# MyMusic — Starter

A minimal music library app. Right now it renders a list of songs and an
empty "Your Playlists" area. Your task is to build it into something more
polished and functional.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Where things are

- `src/data.js`  — the mock song library (songId, songName, artistName,
  duration, albumName, genre, year, coverColor) plus a couple of helpers.
- `src/app.js`   — the app logic and rendering. Start here.
- `src/app.css`  — the styles.
- `index.html`   — the page shell.
